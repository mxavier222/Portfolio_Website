# Reflection

## 1. Identify and share 3 new things you learned from AI in the above task.

I learned how to use JavaScript to make a button interactive. I learned how to generate a random color using JavaScript and apply it to an element on the webpage. I also learned how CSS media queries can be used to make a website responsive on different screen sizes.

## 2. Where did you have to tweak or correct Copilot’s suggestions to suit your needs?

I had to change some of Copilot’s suggestions so they matched the design and structure of my portfolio. For example, I changed the button and JavaScript code so that it worked with my existing HTML elements and CSS. I also had to check the code myself and fix some parts when they did not work as expected.

## 3. How would you explain the difference between using Copilot to generate code for you vs. using it as an effective learning partner?

Using Copilot to generate code means asking it to write code and then simply copying the result into your project. Using Copilot as a learning partner means asking questions, understanding why the code works, and making changes yourself when needed. I think using AI as a learning partner is more useful because it helps me understand programming instead of only giving me the final answer.

## 4. Identify 3 risks of relying too much on AI tools when learning at HackYourFuture.

One risk is that I might copy code without understanding how it works. Another risk is becoming too dependent on AI and finding it difficult to solve problems by myself. A third risk is that AI can sometimes provide incorrect or unsuitable code, so I still need to test the code and use my own judgment.
